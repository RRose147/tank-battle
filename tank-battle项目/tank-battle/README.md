# 钢铁边境：坦克大战 4.0

这是一个继续扩展的原生 HTML、CSS 和 JavaScript Canvas 坦克大战版本，强化了地图节奏、战斗强度和升级反馈。

## 版本 4.0 更新内容

- 新增地图切换：荒原、要塞、废墟三种战场样式
- 更高强度的波次设计，终局扩展到第 7 波
- 新增难度显示与分线战术信息，阶段感更明显
- 强化 boss 机制与精英敌人，战斗压力明显提升
- 保留护盾、能量、冲刺、爆发和掉落升级系统
- 增强 HUD 和操作说明，与正式版游戏节奏更接近

## 运行

直接打开 `tank-battle/index.html`，或在项目根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/tank-battle/`。

## 操作

- `WASD`：移动坦克
- `←` / `→`：调整炮塔方向
- `空格`：发射炮弹
- 点击“重新开始”：重置战局

## 验证

已保留最小可行验证命令：

```bash
python3 -m http.server 8000
```

在浏览器中访问 `http://localhost:8000/tank-battle/` 即可确认页面正常渲染。
